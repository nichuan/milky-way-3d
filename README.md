# 银河系 · Milky Way — 交互式三维星系模拟

基于 Three.js 的真实感银河系（棒旋星系 SBbc）三维场景，约 **159,200 颗恒星** 全部程序化生成，无任何外部贴图资源。

## 运行

```bash
cd milkyway
python3 server.py        # 或: python3 -m http.server 8899
```

浏览器打开 <http://127.0.0.1:8899>（必须通过 HTTP 访问，直接双击 index.html 会因 ES Module 跨域限制无法加载）。

## 交互

| 操作 | 效果 |
|---|---|
| 左键拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| 右键拖动 | 平移 |
| `空格` | 暂停/恢复银河自转 |
| `R` | 自动巡航开关 |
| `L` | 结构标注开关 |
| `H` | 影院模式（隐藏全部 UI） |

## 真实性设计

- **结构**：中央棒 + 核球、四条主旋臂（盾牌-半人马、英仙、人马、矩尺）+ 猎户支臂，对数螺旋（螺距角 12°），太阳位于半径 2.6 万光年处的猎户支臂上
- **恒星**：按光谱型 O–M 的黑体配色加权分布——旋臂偏蓝（年轻星），核球/恒星晕偏橙红（老年星），含 3200 颗带衍射星芒的亮星、球状星团与恒星晕
- **介质**：弥漫气体辉光、贴臂内缘的暗尘埃带（法线混合遮光）、20 团 HII 发射星云（呼吸动画）
- **渲染**：自定义 GLSL 点精灵着色器（星闪烁、距离衰减）、Unreal Bloom 辉光、ACES 色调映射、程序化远景星系与背景星场
- **标注**：银心（人马座 A*）、太阳系脉冲标记、五条旋臂名称，随视角实时投影

## 文件

- `main.js` — 全部场景逻辑（结构采样 / 着色器 / 后期 / 交互）
- `index.html` / `style.css` — 页面与 UI
- `lib/` — Three.js r160 及 addons（本地化，可离线运行）
- `server.py` — 带禁缓存头的本地静态服务器
